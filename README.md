# Investment & Compounding Calculator

> **Try it out:**  [deposit-calculator-for-indian-banks.netlify.app](https://deposit-calculator-for-indian-banks.netlify.app/)

A clean, interactive financial calculator built into a single HTML file. It allows users to estimate and compare returns across Systematic Investment Plans (SIP), Recurring Deposits (RD), and Fixed Deposits (FD). 

The entire project is designed around simplicity. There are no build steps, no complex frameworks to install, and no backend dependencies. It is completely responsive and specifically optimized for mobile use, providing a seamless experience on any screen size.

## Features
* **Three Investment Modes:** Compare SIP, RD, and FD growth trajectories.
* **Target vs. Investment:** Calculate what your money will become, or calculate how much you need to invest to reach a specific target.
* **Mobile First:** The interface is built with touch-friendly sliders, clean inputs, and responsive charts best suited for mobile use.
* **Visual Data:** Includes interactive SVG charts to compare compounding timelines.
* **Single File Simplicity:** All CSS (Tailwind via CDN), JavaScript logic, and HTML structure are contained within `index.html`.

## How to Use
Because of its simplicity, no installation is required. 

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. The application will run instantly locally.

## Deployment
This project is live at [deposit-calculator-for-indian-banks.netlify.app](https://deposit-calculator-for-indian-banks.netlify.app/). It can also be deployed to any static hosting provider (GitHub Pages, Vercel, Netlify) simply by linking the repository.
